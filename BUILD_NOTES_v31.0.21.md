# The Dye Ledger v31.0.21

## Story review surface

- Opens an existing draft or saved Story for review even while background generation is active.
- Allows a joined Shared Match device to read an existing Story without granting host-only editing controls.
- Places the Story and its primary review actions before notes and source transparency.
- Collapses supporting notes and source details when a Story exists, while keeping them open when generation still needs input.
- Scrolls **Review Story** directly to the narrative and compensates for the fixed app header.
- Orders Story actions as **Save Story**, **Edit**, **Regenerate Story**, and **Clear Story**.

## Round-ending consistency

- Uses **Darkness** as both the visible and persisted default reason when a round is ended early.
- Keeps complete and early-ended rounds on the same post-round Story review workflow.

## Compatibility

- No scoring, handicap, settlement, Shared Match data, persistence schema, cloud migration, or Ledger Entry report changes.
- Existing draft Stories, saved Stories, accepted Ledger Entries, and completed rounds remain compatible.

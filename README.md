# The Dye Ledger

Current version: **v27.29**

## What changed in v27.29

- Added a compact Stat Tracking Summary to the Match Summary PDF/export view when stat tracking is enabled and completed holes exist.
- The PDF stat summary includes Player, Fairways, GIR, Avg Putts, Up & Downs, and Sandies.
- The PDF stat summary counts fully completed holes only and excludes partial holes.
- Updated tee creation so a new tee added to an existing course inherits par by hole and stroke index by hole from an existing saved tee while keeping yardages blank.
- Updated manifest and service-worker cache version to v27.29.

# The Dye Ledger v28.12 Build Notes

Focused Game Setup UX release.

## Included
- Reorganized Game Setup into a more natural workflow: Match Details, Today's Match, Players & Teams, Games, Stat Tracking, Optional Features, Handicap Preview, and final actions.
- Added a compact Today's Match summary card that updates as setup selections change.
- Moved Stat Tracking into its own dedicated setup section.
- Moved Shared Match Storage and Scoring Control into collapsed Optional Features panels.
- New matches now default to One Device Scores for Everyone, while existing saved matches preserve their stored scoring mode.
- Updated final action labels to Create Match / Update Match.

## Not Changed
- No scoring calculation changes.
- No game calculation changes.
- No settlement changes.
- No handicap calculation changes.
- No Supabase schema changes.
- No Match Summary, Round Recap, Classic Scorecard, Momentum Chart, or AI scorecard import changes.

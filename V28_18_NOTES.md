# The Dye Ledger v28.18 Build Notes

Focused live scoring UX release.

## Changes
- Added a compact live status line inside the Scoring Input hole header.
- Auto-prioritizes up to three active status items in this order: Nassau, Match/Team Match, Skins, 9-Point, Greenies.
- Keeps Nassau, skins, 9-Point, and greenies summaries concise for iPhone scoring.
- 9-Point status attempts to show all three player totals when space allows.

## Scope Notes
- Display-only enhancement; no scoring, handicap, settlement, Match Summary, AI, Supabase, localStorage, or saved-match schema changes.

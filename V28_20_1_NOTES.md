# The Dye Ledger v28.20.1

Focused Round Notes consolidation and AI Recap UX release.

## Changes
- Consolidated narrative note entry into one authoritative **Round Notes** field in the AI Round Recap area.
- Removed the duplicate general notes field from the Scoreboard tab to reduce confusion.
- Preserved dictation-friendly Round Notes UX with larger text area, guidance text, storytelling examples, and quick prompt buttons.
- Round Notes now remain the single source of narrative context submitted to AI Round Recap.
- Added safe legacy note migration/merging so existing saved notes continue to load and are not lost.
- Updated app version references to v28.20.1.

## Scope
No scoring, stat tracking, settlement, Match Summary, Supabase Course Library, AI Scorecard Import, or Round Recap generation logic was changed.

# The Dye Ledger v28.5 Build Notes

Focused release: Match Summary / Round Recap enhancement.

Changes included:
- Moved The Dye Ledger Round Recap above Games Summary in Match Summary output.
- Moved Player Leaderboard above Final Net Settlement in Match Summary output.
- Increased Match Summary Round Recap body text size by approximately two points.
- Expanded the Round Recap Edge Function prompt from a 5–7 sentence recap to a richer 10–12 sentence recap with a hard cap of 12 sentences.
- Updated recap generation guidance to emphasize gross scoring storylines, gaming results, match momentum, and at least one meaningful highlight for each player where supported by data.

Unchanged:
- No scoring calculation changes.
- No settlement calculation changes.
- No Classic Scorecard changes.
- No Supabase schema changes.
- No localStorage migration.
- No changes to scorecard-import Edge Function.

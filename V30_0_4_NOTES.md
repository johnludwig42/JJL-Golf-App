# The Dye Ledger v30.0.4 – Scoring Input Secondary Controls Repositioning

## Release Theme
Score first. Explore second.

## What Changed
- Moved Show Other Scores and Show Other Stats below the Save Hole action on Scoring Input.
- Converted the controls into lightweight disclosure-style rows so they feel secondary to score entry.
- Preserved host and joined-device toggle behavior, including read-only visibility for unassigned players.
- Kept the compact shared sync indicator inline with the Scoring input title.

## Guardrails
- No scoring calculation changes.
- No Nassau, Match Summary, Final Net Settlement, or stat calculation changes.
- No Supabase schema changes.
- No shared score sync model changes.
- No localStorage schema changes.

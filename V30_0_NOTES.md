# The Dye Ledger v30.0.4 – Shared Match Scoring Completion

Release theme: One shared match. Multiple devices. Zero confusion.

## Added

- Enhanced Shared Match panels on Game Setup and Scoring Input.
- Host/Joined role display, match code, connection status, sync status, last synced time, and assignment summary.
- Participant list showing device role, last seen time, scoring assignments, and sync status.
- Manage Assignments action for host devices in Assigned Players Score Entry mode.
- Clear joined-device messaging: assigned players or waiting for host assignment.
- Human-friendly locked-player message: “You can only score your assigned players.”
- Sync Now visibility in shared-match contexts.
- Round-to-round shared metadata remains carried forward through the v29.3 session foundation.

## Preserved

- No Supabase Course Library schema changes.
- No scoring, handicap, Nassau, Final Net Settlement, Match Summary, or stat calculation changes.
- No localStorage key/schema changes.
- No mandatory authentication.
- Saved matches remain local by default.

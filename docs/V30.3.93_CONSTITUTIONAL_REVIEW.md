# v30.3.93 Constitutional Review

This release implements Principles 1–6, 10–12, 16, 18, and 23 by separating Account, Device, membership, participation, scoring capability, and administrative ownership; constraining cloud access by match membership; preserving local working copies; and retaining all existing rows through transactional migration gates.

The secure join RPC authorizes a temporary Device session for one Shared Match without turning that Device into an Account or Golfer Identity. Membership does not claim a canonical Golfer Identity. Scoring capability remains distinct from Owner/Participant/Viewer terminology and is intentionally transitional until authoritative scoring assignments are represented in the cloud.

No completed RoundRecord is reopened or overwritten. No historical local round is uploaded or claimed. No privacy deletion or identity merge is introduced. The legacy local Reopen for Correction workflow is unchanged and is not extended into the cloud architecture.

Potential constitutional boundary: active match members retain transitional ability to merge shared device/memory metadata into the match row because the existing synchronization contract stores those facts in `course_snapshot`. This is match-scoped rather than global, but field-level host authority should move to narrow RPCs in the future Shared Match synchronization release.

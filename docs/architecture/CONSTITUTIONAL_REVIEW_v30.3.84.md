# Constitutional Review — v30.3.84

## Principles affected

- Principles 6–8: the recap is generated from authoritative Round facts and remains a derived narrative artifact.
- Principle 9: Memories remain contributor facts and must be represented without sacrificing privacy controls.
- Principle 10: a completed RoundRecord is never overwritten by recap generation or acceptance.
- Principles 11–12: post-freeze authoritative recap publication remains deferred to an Owner-authorized Amendment Session.
- Principles 13, 15, and 22: the Round owns its story; competition results remain owned and finalized by their authoritative Round records.
- Principle 23: access, contributor withdrawal, anonymization, preservation, and deletion remain distinct future workflows.

## Compliance

The content specification makes deterministic facts binding, prevents unsupported inference, requires explicit user acceptance, and treats generated output as a draft. Existing recaps and RoundRecords remain untouched. The repository Edge Function is a deployment candidate, not evidence of the unknown live implementation.

## Security and deployment boundary

No production Supabase inspection, deployment, secrets, schema, RLS, Auth, or data changes are included. Test deployment requires an explicitly configured non-production project. Production deployment requires separate Product Owner approval.

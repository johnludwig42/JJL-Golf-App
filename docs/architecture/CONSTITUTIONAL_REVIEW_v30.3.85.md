# v30.3.85 Constitutional Review

v30.3.85 implements Principles 1, 6, 7, 8, 9, 10, 11, 12, 16, and 23.

- Memory corrections preserve stable identity and contributor attribution.
- Frozen RoundRecords are not silently overwritten; authoritative post-freeze publication remains deferred to Amendment Sessions.
- Suggested putts remain distinguishable from reviewed historical facts.
- AI output remains derived, draft-first, and subordinate to authoritative Round facts.
- Local/offline scoring and historical local records remain available and unchanged.
- Nassau rules are stored as versioned Round facts: basis, counting-ball policy, allowance, provenance, and Press inheritance are explicit rather than inferred from mutable defaults.
- Course Net and Match Net are presented separately so living handicap inputs do not obscure the competition facts used by the Round.
- Existing Gross & Net Nassau records retain their legacy interpretation; no historical score, settlement, or RoundRecord is silently rewritten.
- Shared Match uses a fail-closed capability key for the new Nassau policy so older devices cannot silently calculate a different result.

No constitutional conflict was identified. The release does not create cloud ownership, claim identities, deploy server code, or alter production access policies.

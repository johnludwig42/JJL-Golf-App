# Constitution Governance — Version 1.0

The verbatim approved Constitution is stored in `THE_DYE_LEDGER_CONSTITUTION_v1.0.md` and is the highest architectural authority. This companion may explain repository governance but may not alter the constitutional text.

- Lower-level documents and code must conform to the Constitution.
- Apparent conflicts require Product Owner resolution before implementation.
- Formal amendments require explicit Product Owner approval, rationale, effective date, affected principles, and a preserved prior version.
- Every major feature requires a Constitutional Review.

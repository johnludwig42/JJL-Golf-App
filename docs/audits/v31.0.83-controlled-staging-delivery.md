## Proposed fix — awaiting owner approval

Replace the unconditional assigned-player exclusion with guarded reconciliation
of authoritative server facts once no pending or storage-recovery intent exists
for either partner. Preserve newer local edits, pair consistency, assignment and
host authority, timestamp protection and frozen records. Explicitly cover host
corrections with same-account and different-account devices; do not simply disable
the existing guard. Keep scoring, wager amounts, RoundRecords and SQL unchanged.

Before implementation, tests must distinguish pending local writes from already
acknowledged local values. Required regressions: newer host takeover, subsequent
assigned-scorer correction, stale rows, one pending partner, storage failure, reload,
account attribution and completed/frozen facts on both delivery paths.

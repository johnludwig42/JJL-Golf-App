App notes

  • Courses and tees stay manual and editable.
  • Mobile-first iPhone layout now fits the default viewport more naturally without relying on pinch-zoom, with larger touch targets, safer small-screen spacing, and more deliberate small-screen handling for tabs, setup, scoring, scoreboards, and sheets.
  • Audited Team Stroke Play scoring so aggregate net stroke play resolves correctly across the Scoreboard, Games Summary, and Net Payout.
  • Team Stroke Play now defaults to Aggregate scoring, while Best Team Ball remains available as an option.
  • Fixed Game Setup handicap preview so all golfers and their handicap tees reappear correctly when editing a match.
  • Removed a stale Game Setup player-slot render reference that could suppress the player / tee selection block.
  • Improved Share / Save PDF formatting so Match Summary expands all sections before export and scales more cleanly on desktop and iPhone.
  • Classic Scorecard only print now renders as a standalone scorecard and scales to fit the page more reliably in landscape.
  • Fixed a Game Setup selector regression so Course select and Player select work correctly again after recent slot-render updates.
  • Removed the duplicate second player selector in Game Setup so the tap-to-select player card remains the only player picker, while keeping the per-player handicap tee selector unchanged.
  • Improved stat tracking on iPhone so the Fairway Hit option reliably appears on scoring input for par 4 and par 5 holes.
  • Scoreboard Team Stroke Play now shows the selected event using actual stroke totals and winning margin instead of match-play style status.
  • Leaderboard highlights player totals, team totals, match play, skins, and side matches.
  • Match setup now keeps all player tee selectors synchronized across desktop and mobile for up to 8 teams of 4.
  • Share / Save PDF controls now stay synchronized with the currently selected export view.
  • Game setup now includes role-based scoring control for Official Scorer or Team Input events.
  • Score entry can be previewed as Event Admin, Official Scorer, Team Scorer, or Viewer before moving into Supabase.
  • Added optional per-hole stat tracking (fairways, GIR, putts, up & downs, sandies).
  • Reordered the Scoreboard layout and moved Notes from More to Scoreboard.
  • Fixed the Game Setup player assignment flow so team slots save correctly and matches can be created reliably again.
  • App version: v28.21.2
